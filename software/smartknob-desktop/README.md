# SmartKnob Desktop

12種類のアプリをノブで操作する、macOS風の仮想デスクトップです。ブラウザ内のウィンドウとデータが操作対象で、PCのOSや実際のブラウザタブは操作しません。PC専用です。USB未接続でも、画面上のノブとキーボードで使えます。

## 統合デモ

通常は `../smartknob-demo` で `npm ci && npm run dev` を実行し、[OS Demoタブ](http://127.0.0.1:4173/#os)を開きます。ハプティクスとUSB接続を共有し、タブを切り替えても再接続は不要です。OSを離れると動画・音声は停止し、設定とウィンドウは保持します。

以下はOS単独の開発サーバーを起動する手順です。

## 起動

Node.js 22.12以降が必要です。初回はリポジトリのルートから実行します。

```sh
git submodule update --init thirdparty/nanopb
cd software/smartknob-desktop
npm install
npm run dev
```

[http://127.0.0.1:4174](http://127.0.0.1:4174) を開きます。実機を使う場合はPC版Chromeで「USBで接続」を押し、SmartKnobを選択してください。既存のSmartKnob Demoとは別のアプリ・ポートです。

## 操作

- デスクトップのアイコンをダブルクリックして開きます。Dockと上部の「アプリ」からも開けます。
- ウィンドウをクリックするとノブの操作先が切り替わります。タイトルバーで移動し、左上のボタンで閉じる・最小化・最大化できます。
- `←` / `→` で1目盛り、`Shift`＋矢印で10目盛り動かします。
- `Space` は押下、約0.65秒押し続けると長押しです。画面の「押す」ボタンも同様です。
- 画面のノブはドラッグ・ホイール・`−` / `＋` ボタンでも操作できます。展開表示には「長押し」ボタンがあります。
- 実機は1回押しで通常の押下、素早く2回押すと長押しと同じ操作になります。

音楽・オーディオは、最初に画面の再生ボタンを押して音声を有効にしてください。アプリを切り替えても設定値は保持しますが、ページの再読み込みで初期状態に戻ります。

## アプリ

| アプリ | 回転 | 押下 |
|---|---|---|
| ブラウザ | 4つのローカルタブを選択 | 選んだタブを開く |
| ウィンドウ | アプリを選択。写真・タイマー・音楽は強いクリック | アプリを開く |
| タイマー | 1分ずつ調整、5分ごとに吸着 | 開始／一時停止 |
| 写真 | 露出・彩度・色温度を調整。標準値に吸着 | 調整項目を切替 |
| 動画 | 1フレーム／1秒ずつ移動。8章の先頭で強く吸着 | 送り幅を切替 |
| 音楽 | 再生速度・テンポを調整。等速に吸着 | 再生／停止 |
| オーディオ | 左右の定位を調整。中央に吸着 | 試聴／停止 |
| 照明 | 明るさ・色温度を調整。70%・4000 Kに吸着 | 調整項目を切替 |
| レビュー | ファイル内の変更箇所を選択 | 差分を展開／折りたたみ |
| リーダー | ページを移動。章の先頭は強いクリック | 次の章へ移動 |
| マップ | 定番倍率を選択。100%は強いクリック | 100%に戻す |
| 入力 | 星評価・優先度・数量を選択 | 確定して次の項目へ |

動画のチャプターは `src/chapters.js` で共有しています。初期状態の1秒シークは、公式タイムラインデモを基に、吸着強度5・8°間隔・snap point 0.7です。実機で振動が出たため、吸着強度は公式設定10の半分にしています。章の先頭と両端のうち最寄り5点をデバイスに事前設定し、途中は滑らかに回せます。1フレームモードは強度1・1.8°間隔・snap point 1.1で各フレームを刻みます。章一覧・タイムラインの印からも直接移動できます。

長押しの動作はノブパネルに表示します。動画の再生／一時停止は動画内の再生ボタンで操作します。

タイマーは別のアプリを開いても進み、残り時間に合わせて画面とノブの論理目盛りを更新します。実機を物理的に自動回転させる機能ではありません。実行中や一時停止後の回転は残り時間を調整し、長押しで元の設定時間に戻します。

## 実機との接続

本家互換のSmartKnobプロトコルv1をWeb Serialで使用します。通信速度は921600 bps、フレームはProtobuf・COBS・CRC32です。スキーマはリポジトリの `proto/smartknob.proto` から生成し、既存デモの通信処理を再利用しています。

本家の状態通知は `press_nonce` のみで、押下解除や保持時間を含みません。このため実機の長押しは判定せず、約350ms以内の2回押しを代替操作にしています。1回押しの確定にもこの待ち時間があります。

磁石・標準値・1秒シークの章は、現在位置に近い最大5点を先送りするため、吸着点への到達時に通信応答を待ちません。通常クリックは強度1、磁気ディテントは公式デモの半分の5、端のストッパーは1です。磁気ディテントではファームウェアのD項が無効になります。強度5はこの設定に限り、通常のクリックには使いません。

お気に入り・書籍の章境界・1フレームモードの章は、通常クリックを残すためホストから強度を1から2へ更新します。この強調には速い回転時の通信遅延が残ります。

この新しい仮想デスクトップでの実機動作は未検証です。接続後の操作先変更、押下、磁石・強いクリックの感触を確認してください。

## 素材とビルド

`npm run dev`、`npm run build`、`npm test` は `prepare.mjs` を実行します。プロトコルを生成し、既存の `../smartknob-demo/media/big-buck-bunny.mp4` と素材説明を `public/media/` へコピーします。動画をネットから再取得しません。元のローカル動画ファイルが必要です。

- 動画：Big Buck Bunny、© 2008 Blender Foundation、CC BY 3.0。720p・30fpsのローカル素材を使用します。[出典・ライセンス・変換内容](../smartknob-demo/media/README.md)
- 海岸画像：`public/coast.png` はこのデモ用に画像生成で作成した素材です。壁紙と写真補正に使用します。
- 音楽・試聴音：Web Audioで端末内生成します。
- 記事・差分・書籍・地図：同梱データです。外部サービスへの接続は不要です。

```sh
npm test
npm run build
npm run preview
```

テストはアプリの状態遷移、値の範囲、タイマー、ノブ設定、接続・押下処理などを確認します。ビルド結果は `dist/` に出力され、プレビューもポート4174で開きます。
