# SmartKnob Demo

本家互換のSmartKnobをUSBでつなぎ、感触を見て・回して比べるWebアプリです。ファームウェアの変更やChrome拡張は不要です。動画もアプリ内に同梱し、実行時に外部サービスへ接続しません。

## 起動

Node.js 20以上と、デスクトップ版Chrome（Web Serial対応）が必要です。モバイルは非対応です。

```sh
git submodule update --init thirdparty/nanopb
cd software/smartknob-demo
npm ci
npm run dev
```

[http://127.0.0.1:4173](http://127.0.0.1:4173) をChromeで開き、「USBで接続」からデバイスを選択します。別のシリアルモニターが接続中なら、先に閉じてください。ポート番号は `PORT=4174 npm run dev` で変更できます。

開発サーバーは起動時にビルドします。ソース変更後は別のターミナルで `npm run build` を実行してブラウザを再読み込みしてください。配布用の静的ファイルは `npm run build` で `dist/` に生成されます。公開する場合はHTTPSが必要です。`file://` ではなくHTTPのlocalhostまたはHTTPSから開いてください。

終了時は「切断」を使うと、抵抗のない設定を送信してからUSBを閉じます。タブを直接閉じた場合は、最後の感触設定がデバイスに残ることがあります。USBポートの操作権限はユーザーのクリックでのみ要求します。

## ハプティクス

ハプティクスとOS Demoは独立したタブです。ハプティクスタブでは数字キー **1〜8** で感触を選べます。OS Demoでは数字キーを横取りしません。

| キー | テーマ | 比較・特徴 |
| --- | --- | --- |
| 1 | フリー / さらさら | 無段階・無制限 |
| 2 | 粗い / コトコト | 30°ごとのクリック |
| 3 | 細かい / チリチリ | 6°ごとのクリック。粗いと同じ強さの設定 |
| 4 | リミット / むにっ | 滑らかな0〜10の範囲。柔らかい壁／硬い壁 |
| 5 | 2値スイッチ / パチン | OFF／ON。中間を少し越えると切り替わる |
| 6 | ばね / びよん | 中央復帰。なめらか／段付き |
| 7 | 重いダイヤル / ねっとり | 2°の微細な抵抗による近似 |
| 8 | 磁石 / すっ、ぴた | 特定の5か所に吸着。等間隔／不規則 |

未接続でもノブ図を左右にドラッグ、またはスライダーで動きをプレビューできます。接続中は実機の位置に追従します。

抵抗の図は、橙の実線が右へ回したとき、青の破線が左へ回したときの復元力を示します。同じ角度でも現在のディテントによって力が変わるヒステリシスを描いています。黒い線と点が現在位置・力の目安です。表示範囲を越えると反対側から現れます。

この図はファームウェアの `snap_point`、`snap_point_bias`、デッドゾーン、磁気吸着点、端の制限に基づく**位置領域の概念図**です。実測トルク、摩擦、PIDのD項、モーター慣性は再現しません。「ねっとり」は独立した粘性制御ではなく、細かく強いディテントによる実験的な近似です。

## OS Demo

従来の動画デモタブを、12種類のアプリを操作できる仮想デスクトップに置き換えました。[OS Demo](http://127.0.0.1:4173/#os) はハプティクスと同じページで動き、USB接続も共有します。古い `#video`・`#youtube` もOS Demoを開きます。

アイコンをダブルクリック、またはDockをクリックしてアプリを開きます。ウィンドウを選ぶとノブの操作先が切り替わります。画面ノブ、矢印キー、Spaceでも操作できます。実機の長押しは2回押しで代用します。詳しくは [OS Demoの操作ガイド](../smartknob-desktop/README.md) を参照してください。

タブを離れるとOSの動画・音声を停止し、実機の操作先をハプティクスへ戻します。OS内の設定とウィンドウは保持します。USBを取り直す必要はありません。

### 動画のチャプター

OS内の「動画」は同梱のBig Buck Bunnyを使います。初期モードは1秒シークで、章の先頭と動画の両端に強く吸着します。公式 `example-webserial-timeline` のScrollモードと同じ、8°間隔・吸着強度10・snap point 0.7を使い、最寄り5点をデバイスに先送りします。章の間は滑らかに回せます。押すと1フレーム送りへ切り替わり、各フレームでクリックします。チャプター一覧とタイムラインの印から直接移動できます。

目印は `../smartknob-desktop/src/chapters.js` に定義しています。デモ用に付けた位置であり、公式チャプターではありません。

| 時間 | チャプター |
| --- | --- |
| 0:00 | オープニング |
| 0:30 | 森のすみか |
| 1:23 | 草原のバニー |
| 2:30 | 木の上のいたずら |
| 4:56 | 木陰の3匹 |
| 6:00 | 丸太の罠 |
| 7:30 | 杭の罠 |
| 9:00 | エンドクレジット |

動画は [Big Buck Bunny公式配布版](https://peach.blender.org/) をローカルに同梱しています。出典・ライセンスは [media/README.md](media/README.md) を参照してください。起動時に外部の動画サービスへアクセスせず、開発サーバーのHTTP Rangeで配信します。

## 通信と構成

- Web Serial、921600 baud、protocol version 1
- `../../proto/smartknob.proto` からビルド時にProtobufコードを生成
- リポジトリ既存のCOBS処理、CRC32、ACK照合と同一nonceでの再送
- 未送信の設定は最新の1件にまとめ、通信キューが溜まることを防止
- 起動時の状態取得、無応答・抜線の処理、reader/writerの解放
- USBベンダーIDによる制限なし（独自基板のUSBブリッジにも対応）

`src/presets.js` が感触、`src/haptics.js` が概念モデル、`src/visuals.js` がSVG表示、`src/protocol.js` が通信を担当します。OSの実装は `../smartknob-desktop/src/` を共有し、`build.mjs` が同じ配布物へまとめます。OSのCSSはShadow DOM内に隔離しています。

## 検証

```sh
npm test
npm run build
```

自動テストでは通信、ACK・再送・設定集約・切断処理、ヒステリシスと周回、ローカル動画の配信、旧動画コントローラの回帰を確認します。OS側の章境界、接続の共有、タブ切替、動画再生のテストは `../smartknob-desktop` の `npm test` で実行します。

通常クリックは強度1、強調クリックは2、磁石・標準値・章の吸着は10です。`src/feel.js` に公式デモを基準とした設定をまとめています。強度10は磁気ディテント専用です。ファームウェアは磁気ディテントでD項を無効にするため、全位置にクリックがある設定とは分けています。

新しい統合版の感触は実機での確認が必要です。強度の設定値は実測トルクの比率を意味しません。

2026-10-03に、Chromeから実機へ接続し、状態の受信とノブの回転に伴う位置更新を確認しました。実際のクリックの強さ、中央復帰、動画操作との感触の対応は操作者による確認が必要です。磁気ディテントは、プロトコルコメントの典型値0〜1ではなく、同梱の公式シークバーデモが使う10を採用しています。画面テストや通信の模擬テストは、実際の触覚を保証するものではありません。
