# SmartKnob Demo

本家互換のSmartKnobをUSBでつなぎ、感触を見て・回して比べるWebアプリです。ファームウェアの変更やChrome拡張は不要です。動画もアプリ内に同梱し、実行時に外部サービスへ接続しません。

## 起動

Node.js 20以上と、デスクトップ版Chrome（Web Serial対応）が必要です。モバイルは非対応です。

```sh
cd software/smartknob-demo
npm ci
npm run dev
```

[http://127.0.0.1:4173](http://127.0.0.1:4173) をChromeで開き、「USBで接続」からデバイスを選択します。別のシリアルモニターが接続中なら、先に閉じてください。ポート番号は `PORT=4174 npm run dev` で変更できます。

開発サーバーは起動時にビルドします。ソース変更後は別のターミナルで `npm run build` を実行してブラウザを再読み込みしてください。配布用の静的ファイルは `npm run build` で `dist/` に生成されます。公開する場合はHTTPSが必要です。`file://` ではなくHTTPのlocalhostまたはHTTPSから開いてください。

終了時は「切断」を使うと、抵抗のない設定を送信してからUSBを閉じます。タブを直接閉じた場合は、最後の感触設定がデバイスに残ることがあります。USBポートの操作権限はユーザーのクリックでのみ要求します。

## ハプティクス

ハプティクスと動画デモは独立したタブです。数字キー **1〜8** で感触を選べます。タイムスタンプ入力中・セレクト操作中は数字キーを横取りしません。

| キー | テーマ | 比較・特徴 |
| --- | --- | --- |
| 1 | フリー / さらさら | 無段階・無制限 |
| 2 | 粗い / コトコト | 30°ごとのクリック |
| 3 | 細かい / チリチリ | 6°ごとのクリック。粗いと同じ強さの設定 |
| 4 | リミット / むにっ | 滑らかな0〜10の範囲。柔らかい壁／硬い壁 |
| 5 | 2値スイッチ / パチン | OFF／ON。中間を少し越えると切り替わる |
| 6 | ばね / びよん | 中央復帰。なめらか／段付き |
| 7 | 重いダイヤル / ねっとり | 2°の微細な抵抗による近似 |
| 8 | 磁石 / すっ、ぴた | 特定の5か所に吸着。等間隔／不規則 |

未接続でもノブ図を左右にドラッグ、またはスライダーで動きをプレビューできます。接続中は実機の位置に追従します。

抵抗の図は、橙の実線が右へ回したとき、青の破線が左へ回したときの復元力を示します。同じ角度でも現在のディテントによって力が変わるヒステリシスを描いています。黒い線と点が現在位置・力の目安です。表示範囲を越えると反対側から現れます。

この図はファームウェアの `snap_point`、`snap_point_bias`、デッドゾーン、磁気吸着点、端の制限に基づく**位置領域の概念図**です。実測トルク、摩擦、PIDのD項、モーター慣性は再現しません。「ねっとり」は独立した粘性制御ではなく、細かく強いディテントによる実験的な近似です。

## 動画デモ

[Big Buck Bunny – Blender Foundation](https://peach.blender.org/) の公式配布版をダウンロードし、`media/big-buck-bunny.mp4` として同梱しています。YouTubeの埋め込みは使わず、HTMLの動画要素を独自の操作UIから制御します。インターネットの速度やYouTube側のバッファリングに左右されません。

「再生 / 一時停止」と「消音 / 音声オン」を使用できます。動画のメタデータ読み込み後は、再生前でもシーク・速度モードを使えます。古い `#youtube` のURLも動画デモを開きます。

- **位置**：回転量でシークします。1秒を1位置に対応させ、シーンの目印で磁気吸着します。回転角は1秒あたり1°／3°／6°。タイムラインや再生位置スライダーからも操作できます。
- **速度**：ノブを右へひねると早送り、左へひねると巻き戻し。中央復帰のばねで、中央は停止します。画面の速度スライダーも離すと停止します。最大±32倍。
- 速度操作は停止した動画の `currentTime` を経過時間に応じて更新します。逆方向にも同じ応答でシークでき、速度モード中の音声は出ません。デコード中は次の要求を最新の1件に集約します。フレーム単位の編集精度を保証するものではありません。
- ハプティクスタブへ移動すると、動画の再生・シーク・速度操作を停止します。ページが非表示になった場合も速度操作を止めます。

シーンの目印は `src/player.js` の `DEMO.scenes` に定義しています。ページ内の動画を確認して付けたデモ用の目印であり、公式チャプターや全カットの境界ではありません。

| 時間 | シーンの目印 |
| --- | --- |
| 0:00 | オープニング |
| 0:30 | 森のすみか |
| 1:23 | 草原のバニー |
| 2:30 | 木の上のいたずら |
| 4:56 | 木陰の3匹 |
| 6:00 | 丸太の罠 |
| 7:30 | 杭の罠 |
| 9:00 | エンドクレジット |

動画の出典、ライセンス、変換方法は [media/README.md](media/README.md) に記載しています。`npm run build` は動画を `dist/media/` にコピーします。開発サーバーはHTTP Rangeに対応し、必要な範囲をストリーミングします。

追加のタイムスタンプは `1:23 4:56`、または `1:02:03` の形式で入力できます。現在位置に近い5か所をデバイスへ送り、回転に応じて更新します。更新時には位置・位置nonceを維持し、ノブを再センタリングしません。通常再生やマウス操作で再生位置が変わった場合は、手が止まってから再同期します。

## 通信と構成

- Web Serial、921600 baud、protocol version 1
- `../../proto/smartknob.proto` からビルド時にProtobufコードを生成
- リポジトリ既存のCOBS処理、CRC32、ACK照合と同一nonceでの再送
- 未送信の設定は最新の1件にまとめ、通信キューが溜まることを防止
- 起動時の状態取得、無応答・抜線の処理、reader/writerの解放
- USBベンダーIDによる制限なし（独自基板のUSBブリッジにも対応）

`src/presets.js` が感触、`src/haptics.js` が概念モデル、`src/visuals.js` がSVG表示、`src/protocol.js` が通信、`src/video.js` がシーク／速度制御を担当します。

## 検証

```sh
npm test
npm run build
```

自動テストでは既知のCRC32、壊れたフレーム、負の整数・小数・磁気吸着点のProtobuf、分割受信、ACK・再送・設定集約・切断処理、ヒステリシスと周回、シーク時の位置維持、速度の方向・経過時間・停止・端の制限を確認します。ローカル動画については再生前のシーク、デコード待ちの集約とキャンセル、読み込み・再生エラー、動画配信のRange/HEADも確認します。

ローカル動画版は22件の自動テストとビルドが成功しています。デスクトップのブラウザで、再生前の1:23へのシーク、通常再生と一時停止、消音、正逆の速度操作、中央停止、タブを離れた際の停止を確認しました。動画は同じlocalhostから読み込み、外部プレーヤーやスクリプトは使用しません。ローカル動画版での実機操作は再確認が必要です。

2026-10-03に、Chromeから実機へ接続し、状態の受信とノブの回転に伴う位置更新を確認しました。実際のクリックの強さ、中央復帰、動画操作との感触の対応は操作者による確認が必要です。設定強度は本家プロトコル推奨の0〜1内に収めています。画面テストや通信の模擬テストは、実際の触覚を保証するものではありません。
